# Memory. 9,872 resident experts (64.3%) on native scales, the hot-read ring's 128 slots (below)
# and two 512K lanes (the lossless scale pack, which fits more, is not ported). scripts/memguard.sh
# stops the server when MemAvailable falls below KEEP_FREE_GB. The same two-lane requests
# (2026-10-25) bottomed at 6.45 / 8.00 GiB (rank 0 / 1) with 10,000 residents and no ring, and at
# 5.42 / 6.31 with 10,000 and the ring (1.2 GB a rank), so the ring's slots come out of the
# residents. One lane holds 10,000 and the ring: its second lane's memory is the ring's.
RUST_BUDGET=10000
KEEP_FREE_GB=4

# Two lanes: a second request decodes beside the first instead of queueing, and a new prompt
# prefills alone while the other lane waits; both route to the one hot-read ring. Two prose
# requests at once: 41.2 tok/s together (22.8 / 20.6 each) with the ring, 40.6 without (the same
# requests, one boot an arm). 1 serves one request at a time.
RUST_LANES=2
# Context pages (docs/paged-kv.md): both lanes' caches come out of one pool of 1.5M tokens, so
# one lane reaches 1M while the other holds 512K, for 2.19 GB a rank (two fixed 512K lanes took
# 2.14). A step short of pages swaps the newest request out to the prefix disk tier
# (DSV41_PREFIX_DISK=1, required) and brings it back, exactly, once there is room.

# Speculative decoding (SPEC=0: plain decode): DSpark drafts, at a depth the drafter's confidence
# picks each step (RUST_DEPTH: window, confidence or a fixed depth), behind the copy drafter, a
# CPU prompt lookup (RUST_COPY_DRAFT=0 turns it off; 2.25x on a file rewrite). Expert top-p
# (RUST_EXPERT_TOPP=0.90) measured slower: drafter acceptance fell (rust/PORT.md).

RUST_DEPTH=confidence
